# 05_relatorio

Esta pasta reúne os materiais de entrega, síntese e comunicação dos resultados finais.

## Objetivo

Organizar as evidências e os achados do projeto em formato adequado para apresentação, revisão, documentação e tomada de decisão.

## Conteúdo esperado

- relatórios finais;
- resumos executivos;
- gráficos, tabelas e ilustrações;
- conclusões e recomendações;
- anexos e evidências técnicas;
- materiais reutilizáveis para apresentação ou entrega.

## Uso recomendado

Os relatórios devem refletir fielmente o que foi validado e o que permanece em aberto. Esta área é o ponto de comunicação entre o trabalho técnico e o público destinatário.
