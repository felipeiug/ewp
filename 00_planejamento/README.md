# 00_planejamento

Esta pasta concentra a fase inicial do projeto, onde são definidos o objetivo, o escopo, as premissas e a direção geral do trabalho.

## Objetivo

Registrar o ponto de partida do projeto antes das etapas analíticas e técnicas. Aqui é onde se responde perguntas como:

- qual problema será resolvido;
- qual é o escopo do trabalho;
- quais são as metas e entregáveis;
- quais restrições e hipóteses iniciais existem;
- qual sequência de execução será adotada.

## Conteúdo esperado

- definições do problema;
- objetivos e critérios de sucesso;
- escopo e limites;
- contexto técnico e de negócio;
- premissas iniciais;
- cronograma ou ordem de execução;
- referências e dependências.

## Uso recomendado

Os artefatos gerados nesta etapa devem servir de base para as demais pastas do workspace. O conteúdo desta pasta deve ser estável, mas pode ser revisado conforme novas informações forem incorporadas.
