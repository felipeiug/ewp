# 01_dados

Esta pasta é dedicada ao levantamento, organização e preservação das fontes de dados do projeto.

## Objetivo

Garantir que todas as entradas do projeto estejam identificadas, documentadas e separadas das transformações e dos resultados finais.

## Conteúdo esperado

- arquivos brutos ou fontes primárias;
- metadados e origem dos dados;
- descrição de coleta, frequência e qualidade;
- convenções de nomenclatura;
- registros de proveniência, quando aplicável;
- evidências que servem como base para análise e modelagem.

## Uso recomendado

A pasta `input/` deve manter as fontes originais intactas, sem alteração. A pasta `output/` pode conter versões filtradas, consolidadas, validadas ou organizadas para uso nas etapas seguintes.
