# REQUISITOS

Esta pasta reúne os critérios técnicos, funcionais e de engenharia que definem o que o projeto precisa satisfazer.

## Objetivo

Separar requisitos de hipóteses, preferências ou decisões improvisadas. O foco é garantir clareza e verificabilidade.

## Conteúdo esperado

- requisitos funcionais;
- requisitos técnicos;
- restrições e limites;
- unidades e convenções;
- critérios de aceitação;
- metas e condições de validade.

## Uso recomendado

Os requisitos devem ser tratados como referência formal para o projeto. Eles orientam a modelagem, a validação e a avaliação do resultado final.
