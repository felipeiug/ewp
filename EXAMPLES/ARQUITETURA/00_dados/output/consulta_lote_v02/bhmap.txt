						<p>Há dois serviços que disponibilizam os mapas do BHMap, estes serviços seguem os protocolos WMS e WFS
							especificados pela OGC.</p>
						<div data-role="collapsible-set" data-content-theme="c">

							<div data-role="collapsible">
								<h3>WMS</h3>
								<p>O padrão OpenGIS “Web Map Service Interface” (WMS) fornece uma interface simples HTTP para solicitações
									de imagens de mapas geo-registradas de uma ou mais bases de dados geoespaciais distribuídas. Ou seja, é um
									protocolo para servir imagens de mapas (PNG, JPEG ou GIF) georreferenciadas através da Internet que são geradas
									por um servidor de mapas utilizando dados de um banco de dados GIS.</p>
								<p>
									<b>Caminho para o serviço:</b>
								</p>
								<div class="well">
									<code>http://bhmap.pbh.gov.br/v2/api/idebhgeo/wms</code>
								</div>

							</div>

							<div data-role="collapsible">
								<h3>WFS</h3>

								<p>WFS – “Web Feature Service Interface Standard” é um padrão que se refere ao envio e recebimento de dados
									geoespaciais através de HTTP. Fornece uma interface que permite solicitações de características geográficas
									através da web usando independentes plataformas. Fonte: https://concani3.wordpress.com/</p>

								<p>
									<b>Caminho para o serviço:</b>
								</p>
								<div class="well">
									<code>http://bhmap.pbh.gov.br/v2/api/idebhgeo/wfs</code>
								</div>
							</div>
						</div>

						<h2>API</h2>

						<p>A API do BHMAP utiliza mesma url para acesso desktop, mantendo a especificação dos serviços padrão da OGC:</p>

							Serviço de dados: <code>http://bhmap.pbh.gov.br/v2/api/idebhgeo/wfs</code>
						</div>
								
						<p>	Os parâmetros das requisições podem ser consultados com mais detalhes em:</p>
						<p class="well">
							WMS (serviço de imagens): <a target="_blank" href="http://docs.geoserver.org/2.11.1/user/services/wms/reference.html#getmap">http://docs.geoserver.org/2.11.1/user/services/wms/reference.html#getmap</a>
						</p>
						<p class="well">
							WFS (serviço de dados): <a target="_blank" href="http://docs.geoserver.org/2.11.1/user/services/wfs/reference.html#getfeature">http://docs.geoserver.org/2.11.1/user/services/wfs/reference.html#getfeature</a>
